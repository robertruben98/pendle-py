# pendle-py

Python client for the Pendle Finance v2 API — yield/PT-YT markets, APYs, swap calldata. Sync + async, Pydantic v2.

## Install

```bash
pip install pendle-py
```

The distribution is `pendle-py`; the import package is `pendle`.

## Quick start

```python
import pendle
```

See the [API reference](api.md) for the full surface.
